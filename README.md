# Our pay through time

A single-page website showing how pay at Waipapa Taumata Rau/University of
Auckland has changed over time once inflation (CPI) or general wage growth
(LCI) is taken into account. Published by the TEU UoA branch at
<https://teu-uoa.github.io/payatuoa/>.

## What's here

| File | What it is |
| --- | --- |
| `index.html` | The whole website: page, styling, code and data in one file. |
| `payscale.csv` | The current academic salary scale. |
| `annualpayincrease.csv` | The across-the-board pay rise in each year's collective agreement. |
| `averagepay.csv` | Average academic and professional pay from the annual reports. |
| `indexes.csv` | Quarterly CPI and LCI, as published by Stats NZ. |
| `makedata.R` | Reads the three CSV files and writes the data into `index.html`. |

The data in `index.html` sits between the lines
`// ---- DATA (generated by makedata.R) ----` and `// ---- END DATA ----`.
Don't edit it by hand. Edit the CSV files and run the script instead.

## Updating the data

1. Edit the CSV file(s) as described below. Any spreadsheet program or text
   editor will do, but keep them as CSV when saving.
2. Run the script. It needs R with the `tidyverse` and `jsonlite` packages.

   ```bash
   Rscript makedata.R
   ```

   It prints the last published quarter of each index, so you can check the
   new data was picked up.
3. Open `index.html` in a browser to check it looks right.
4. Commit and push. The website updates a minute or two later.

   ```bash
   git add -A
   git commit -m "Add September 2026 CPI"
   git push
   ```

### New CPI or LCI figures (quarterly)

Stats NZ releases CPI about three weeks after the end of each quarter and LCI
about five weeks after. In `indexes.csv`, add a row for the new quarter, or
fill in the blank cell if the other index is already there:

```
quarter,cpi,lci
...
2026Q2,1359,1273.12
2026Q3,1374,
```

- `quarter` is written like `2026Q3`, where Q1 = March, Q2 = June,
  Q3 = September and Q4 = December.
- `cpi` is the Consumers Price Index, all groups (Infoshare series
  `CPIQ.SE9A`).
- `lci` is the Labour Cost Index, all sectors combined, all salary and wage
  rates, base June 2009 quarter = 1000 (series `LCIQ.SG53Z9`). Copy it from
  Table 1 of the "Labour cost index (salary and wage rates)" spreadsheet in
  each Labour Market Statistics release: the "All sectors combined" column
  under "Index of all salary and wage rates". Stats NZ also publishes the
  same index on a June 2017 base (`LCIQ.SD53Z9`). Don't mix the two; the
  page only cares about ratios, but every row must be on the same base.
- Only enter published figures. A blank cell at the end of a column means
  "not out yet". Blanks in the middle of a column are an error.
- If Stats NZ revises an earlier quarter, just change that number.

### Projections

Past the last published quarter, the page projects each index forward at an
assumed annual rate and tells the reader it has done so. The rates are set
near the top of `makedata.R`:

```r
assumed_rates <- list(
  cpi = c("2026" = 4, "2028" = 3),
  lci = c("2028" = 3)
)
```

Read each entry as "this rate up to the end of this year". The example means
CPI grows at 4% a year to the end of 2026, then 3% a year to the end of 2028.
Projections stop at the last year named. The note shown on the website is
written from these numbers, so change them here and the wording follows.

### A new pay round (yearly)

Add a row to `annualpayincrease.csv` with the year and the across-the-board
rise as a percentage (`2` means 2%):

```
year,pay_rise_pct
...
2027,2.5
```

Then replace `payscale.csv` with the new scale. Every row should carry the
new year, and the grade names are what appear on the website:

```
grade,year,salary
L1,2027,102283
...
```

The year in `payscale.csv` must also have a row in `annualpayincrease.csv`.

### New annual report (yearly)

Add a row to `averagepay.csv` for that year:

```
year,academic,professional
...
2026,158210,92475
```

These are total salary cost divided by total FTE for academic and
professional staff, from the University's annual report.
